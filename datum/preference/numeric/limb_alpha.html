/tg/ Station 13 - Modules - Types — Var Details

limb_alpha
/datum/preference/numeric/limb_alpha

Base type for a single bodypart's alpha slider. Stores the chosen value in dna.features under "limb_alpha_[limb_zone]", which /obj/item/bodypart/proc/update_limb reads.

Vars

enabledIf FALSE, the slider is hidden entirely. Kept around so head/chest can be re-enabled later.
limb_zoneThe BODY_ZONE_* this slider controls. Also forms the dna.features key.
requires_toggleIf TRUE, this slider only shows (and only applies) when the per-limb toggle is enabled.
